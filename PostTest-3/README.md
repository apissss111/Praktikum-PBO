## Posttest 3

Pada Posttest 3 program diperbarui dengan menerapkan konsep:

### Inheritance

Program menggunakan konsep inheritance dengan membuat class turunan dari class `Event`.

### Parent Class

* `Event` digunakan sebagai class induk yang menyimpan data dasar event seperti `namaEvent` dan `tanggal`.

### Child Class

Program memiliki dua class turunan:

* `EventVolunteer`
* `EventSponsor`

Kedua class tersebut mewarisi atribut dan method dari class `Event`.

### Tipe Inheritance

Program menggunakan **Hierarchical Inheritance**, yaitu satu parent class memiliki lebih dari satu child class.
